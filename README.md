# tcg-text-results

複数のTCGのカードテキストを形態素解析（Sudachi）し、読みやすさ・文体を比べた結果です。
レポート（`report*.md`）に表と考察、CSV に集計値があります。最終更新: 2026-10-01

- 図（画像）・元のカードデータ・カード本文を含む明細CSVは公開していません
- 解析コードは非公開です
- レポート・CSV の例文は、カード本文・フレーバーの先頭10文字までの引用です（続きは「…」）
- CSV の末尾の `作成日` 列と、レポート先頭の「作成日」は、その結果を作った日です
- 各カードの文章の著作権は各権利者に帰属します

## ゲームの略称

CSV では次の略称を使います。レポートでは日本語名で書いています。

| 略称 | ゲーム | 効果テキスト | フレーバー |
|---|---|:-:|:-:|
| `ygo` | 遊戯王 | ○ | ○ |
| `mtg` | マジック：ザ・ギャザリング | ○ | ○ |
| `poke` | ポケモンカード | ○ | ○ |
| `op` | ワンピースカード | ○ | |
| `vg` | カードファイト!! ヴァンガード | ○ | ○ |
| `dm` | デュエル・マスターズ | ○ | |
| `bs` | バトルスピリッツ | ○ | |

- **効果テキスト**: ゲームのルールを書いた文。**フレーバー**: 世界観・雰囲気の文（効果とは別）
- 1件 = 1カード（同名カードの再録は1回だけ数える）。`card_length` だけは物理的な1面（両面カードは面ごと）

## フォルダと内容

### `output/readability/` 効果テキストの読みやすさ・冗長さ
- `report.md` : ゲーム間の比較表（中央値）、冗長さ、1文が最も長いカード
- `summary.csv` : ゲームごとに、各指標の平均 `_mean`・中央値 `_median`・90%点 `_p90`（上位10%の境目）

| 列 | 意味 |
|---|---|
| `blocks` | カード数 |
| `mattr100` | 語彙の多様さ（MATTR）。100語の窓で異なり語の割合を平均。低いほど同じ語の繰り返しが多い |
| `zlib_ratio` | 圧縮率（zlib で圧縮した後のサイズ÷元のサイズ）。低いほど繰り返しが多い。コーパスの大きさの影響を受ける |
| `chars` | 文字数（記号・空白を除く） |
| `morphs` | 形態素数（助詞なども含み、記号は除く） |
| `morphs_per_sentence` | 1文あたりの形態素数 |
| `longest_sentence_chars` | 最も長い文の文字数 |
| `commas` | 読点「、」の数 |
| `conditions` | 条件を表す語（場合・なら・とき・時・たら・限り・かわりに・以外・まで）の数 |
| `bracket_depth` | カッコ（「」『』（）【】など）の最大の入れ子の深さ |
| `kanji_ratio` / `kata_ratio` | 漢字・カタカナの文字の割合 |

### `output/card_length/` 1カードあたりの効果テキストの文字数
- `summary.csv` : `units` 件数 / `max` 最大 / `median` 中央値 / `min` 最小 / `mean` 平均 / `p90` 90%点（文字数）
- `report.md` : 比較表と、各ゲームの最長・最短のカード

### `output/anaphora/` 照応表現（前の処理の結果を指す言い方）
- `summary.csv` : 種類ごとに、含むカードの割合 `_cards`（0〜1）と、1000字あたりの回数 `_per1000`
  - `それ` : 「それ」「それら」 / `その+名詞` : 「そのカード」「そのモンスター」など / `した+名詞` : 「宣言したカード」「選んだモンスター」など / `これ` : 「これ」「これら」
  - `any_*` : いずれかを含む。`cards` 列はカード数
- `report.md` : 同じ表と、ゲームごとの「その+名詞」「した+名詞」の上位

### `output/distance/` ゲーム間の言語距離
- `distance_vocab.csv`（語彙＝何について書くか）/ `distance_skel.csv`（文型＝どう書くか）/ `distance_char.csv`（文字2連続＝表記の癖）
- ゲーム×ゲームの行列。値は Jensen-Shannon 距離（0 = 同じ、大きいほど違う）。**対角線は同じゲーム内の2組の距離**で、ゆらぎの目安
- 形態素数をそろえて無作為に抜き出して比べています

### `output/flavor/` フレーバーテキストの文体
- `summary.csv` : 文末の形の割合（`体言止め` `過去` `断定` `用言終止` `助詞止め` `セリフ` `その他`）。`flavors` フレーバー数、`sentences` 文数、`sent_per_flavor` 1件あたりの文数、`fit_flavor_ratio` 「体言止め＋簡単な説明文だけ」仮説に合致したフレーバーの割合、`all_taigen_ratio` 全文が体言止めのフレーバーの割合
- `repeat_summary.csv` : 言い回しの重複。`sampled_*` は件数をそろえた無作為抜き出しの平均、`full_*` は全件
  - `same_sentence` 他にも全く同じ文がある文の割合 / `skeleton_top` 文型の上位10個が占める割合 / `skeleton_kinds` 文型の種類数÷文数 / `ending_top` 文末3語の上位10個が占める割合 / `common_phrase` 他の2つ以上のフレーバーにも出る5語の並びを含む文の割合
- `phrases_<略称>.csv` : よく出る語5個の並びと、出現したフレーバー数
- `skeletons_<略称>.csv` : よく出る文型（内容語を品詞に置き換えた形）、出現数、例文（先頭10文字）
- `color_words.csv` : MTGフレーバーの色別の頻出語。`color` 色 / `flavors` 出現フレーバー数 / `per_1000` 1000件あたり / `z` 他の色に比べた特徴の強さ（対数オッズ比のz値）
- `report.md`（文末分類と仮説の検証）、`report_repeat.md`（重複）、`report_color.md`（MTGの色別）

### `output/flavor_similarity/` フレーバーが「どのゲームか」の判別
- `confusion.csv` : 混同行列。行 = 正解のゲーム、列 = 予想したゲーム（割合。対角線が正解率）
- `keywords_<略称>.csv` : そのゲームの決め手になる語。`df_in_game` そのゲームで出るフレーバー数 / `df_other` 他ゲームで出る数 / `log_ratio` 偏りの強さ
- `report.md` : 正解率、紛らわしい例、他のゲームと最も似ている組、決め手の語
