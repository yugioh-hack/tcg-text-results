# tcg-text-results

複数TCG（遊戯王・MTG・ポケモンカード・ワンピース・ヴァンガード・デュエルマスターズ・バトルスピリッツ）の
カードテキストを形態素解析（Sudachi）し、読みやすさ・文体を比べた結果です。

- `output/<解析名>/report*.md` : 解析レポート（表と考察）
- `output/<解析名>/*.csv` : 集計結果。末尾の `作成日` 列は結果を作った日
- 図（画像）・元のカードデータ・カード本文を含む明細は公開していません
- 解析コードは非公開です。レポート中の引用は、分析のための短い例示に限っています

最終更新: 2026-10-01

各カードの文章の著作権は各権利者に帰属します。
